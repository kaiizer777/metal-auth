# Security Policy

## Reporting a Vulnerability

The `metal-auth` team takes the security of our library seriously.

If you discover a security vulnerability, please **DO NOT** open a public issue on GitHub. Instead, report it privately via email:

- **Email**: security@metal-auth.dev

### Information to Include
When reporting a vulnerability, please provide:
- A description of the issue and potential impact
- Affected version(s)
- Steps to reproduce or a minimal proof of concept (PoC)
- Any proposed remediation or patches

### Response Timeline
- **Initial Response**: Response time TBD (we aim to acknowledge reports within 48–72 hours).
- **Resolution**: We will coordinate disclosure timelines and prepare a patch release before public disclosure.
