# Deferred Scope (Not in v1)

The following features are intentionally out of scope for the v1 milestone to keep the core small, secure, and rigorously tested:

- Passkeys/WebAuthn (planned for v2+)
- 2FA/TOTP (planned for v2+)
- Magic Links (planned for v2+)
- SAML/SCIM (planned for v2+)
- Multi-tenant/Organizations (planned for v2+)
- Additional DB adapters (planned for v2+)
